# Electronic Physics Projects — Fall 2025

This repository is organized as **one project per Git branch**, based on the Electronic Physics Projects (Fall 2025) project list.

Each project branch contains a build-focused README with:
- project overview and physics concepts
- bill of materials (BOM)
- pin-by-pin wiring
- firmware/software starter implementation
- assembly and testing procedure
- safety notes
- optional enclosure/mechanical design guidance where useful
- relevant open-source references when applicable

> Educational prototypes only. Mains electricity, batteries, lasers, medical sensing, moving mechanisms, fire suppression, and water systems require appropriate supervision and safety practices.
